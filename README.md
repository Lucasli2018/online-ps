# 在线 PS · 图片编辑器

一个**零依赖、单文件**的在线图片编辑器，类似在线版的 Photoshop。双击 `index.html` 即可使用，也可部署到任意静态托管（已上线 Cloudflare Pages）。

- 线上地址：https://online-ps.pages.dev/
- 代码仓库：https://gitee.com/li-luoqiang/online-ps

## 特性

### 图层系统
- 多图层：新建 / 复制 / 删除 / 向下合并
- 图层显隐、透明度调节、缩略图预览、双击重命名

### 绘制与文字
- 画笔、橡皮擦（可调大小与不透明度）
- 形状：矩形、椭圆、直线、箭头
- 文字工具（浮动输入框，回车提交）
- 渐变工具：线性 / 径向双色填充
- 裁剪、取色

### 调整与滤镜
- 基础调整：亮度、对比度、饱和度、色相、模糊（实时预览 + 应用）
- 一键滤镜预设：复古、鲜艳、冷调、暖调、黑白、反相、素描、柔光
- 锐化（卷积）

### 变换
- 自由变换：选中图层显示变换框，拖控制点缩放、顶部圆点旋转，`Enter` 应用 / `Esc` 取消
- 图层 / 画布 水平、垂直翻转
- 画布旋转 90°、改尺寸

### 蒙版、选区与曲线调色
- **图层蒙版**：为图层添加蒙版；「编辑蒙版」后画笔涂白=显示、涂黑=隐藏（橡皮擦反向）。蒙版与图层一起变换/翻转/合并/导出
- **矩形 / 椭圆选区**：拖拽生成选区（蚂蚁线边界），限制后续绘制与曲线范围
- **魔棒**：基于颜色容差的洪水填充选区，右侧「魔棒容差」滑杆控制容差（0–150）
- **选区操作**：全选 / 取消 / 反选（作用于蒙版逻辑一致）
- **曲线调色**：RGB / R / G / B 四通道独立曲线，点击曲线添加控制点、拖动调整、双击删除中间点（端点保留）。实时预览，点「应用曲线」落盘（含选区裁剪）
- **对齐参考线**：选「参考线」工具从画布内拖动新建水平/垂直参考线；移动/形状/文字自动吸附；拖动已有参考线可移动，双击删除；顶部「显示/隐藏」「清除全部」

### 图层混合模式
- 每个图层图层面板下拉框可选混合模式：**正常 / 正片叠底 / 滤色 / 叠加 / 变暗 / 变亮 / 颜色减淡 / 颜色加深 / 强光 / 柔光 / 差值 / 排除 / 色相 / 饱和度 / 颜色 / 明度**
- 合成时按模式用 Canvas `globalCompositeOperation` 叠绘（与上方图层的合成结果混合）；最底层始终按「正常」处理，避免透明背景被正片叠底等清零
- 混合模式与透明度、蒙版同时生效，并随工程文件保存

### 可编辑路径
- 选「路径」工具（P）后：
  - **选区→路径**：把当前选区轮廓追踪（Moore 邻域边界跟踪 + Douglas-Peucker 简化）为可编辑矢量多边形路径
  - **路径→选区**：把选中路径填充回选区蒙版
  - **描边 / 填充**：把路径烤进当前图层（描边用前景色，填充用前景色，受不透明度影响）
  - **编辑锚点**：点击选中路径，拖动白色锚点编辑形状；双击路径切换闭合 / 开放
  - 路径列表显示在右侧「路径」面板，可点击选中、删除
- 路径是矢量覆盖层（渲染在叠加画布上），不随导出输出，需「描边 / 填充」才会落到像素图层

### 内容识别填充（近似）
- 在选区内智能补全：算法为**扩散（Laplacian / 热扩散）平滑基底 + 从最近源像素带随机抖动的纹理采样**混合，得到近似的无缝补全
- 右侧「填充范围」滑杆控制纹理取样的搜索半径（4–40）；点「内容识别填充」执行，作用于当前图层（蒙版编辑模式下作用于蒙版）
- 属近似算法，适合去除小物体 / 瑕疵；大区域与复杂纹理建议多试几次或配合克隆思路


### 视图与缩放
- 状态栏缩放控制：`−` / `+` 步进缩放，**缩放比例下拉**（适应屏幕 / 25% / 50% / 75% / 100% / 125% / 150% / 200% / 300% / 400% / 600% / 800%；非预设的中间值会动态显示在列表里）
- 「适应屏幕」一键适配窗口大小；窗口尺寸变化时若处于适应模式会自动重算
- `Ctrl+滚轮` 缩放、`Ctrl+0` 适应屏幕、`Ctrl+1` 100%、`Ctrl + / -` 步进缩放
- 视图缩放采用「布局尺寸=缩放后尺寸」方案：打开大图自动缩放完整可见，不产生假滚动条；放大超界后可正常滚动平移

### 颜色
- 前景色 / 背景色双色板，一键交换（X）

### 导出与工程
- 导出 PNG / JPG / WebP
- 保存工程（`.json`，含全部图层）、打开工程继续编辑
- 打开本地图片作为底图

### 历史
- 基于快照的撤销 / 重做（上限 30 步）
- 可点击的历史面板：点任意步骤跳转到该状态

## 技术说明

- 纯原生 HTML5 Canvas + JavaScript，**零第三方依赖、零构建**
- 图层 = 各自的离屏 `<canvas>`，合成时按透明度叠绘到主画布
- 历史快照 = 克隆各图层 canvas（同步、无异步解码坑）
- 视图缩放：主画布用 CSS `transform: scale()` 显示，外层布局尺寸同步为缩放后尺寸（`transform-origin:0 0` + `margin:auto`），大图适配不裁切、放大后可正常滚动；鼠标坐标经 `getBoundingClientRect` 反算，任意缩放下映射精确
- 站点图标：独立文件 `favicon.svg`——深色圆角底 + 珊瑚描边，三条错落图层条呼应**图层系统**，加粗 **Ps** 字样；由 `index.html` 以 `<link rel="icon">` 引用
- 自由变换通过 `translate + rotate + drawImage` 实现
- 移动端未专门适配，建议使用桌面浏览器

## 本地运行

直接双击 `index.html`，或起一个静态服务器：

```bash
npx serve .        # 或 python -m http.server
```

## 部署（Cloudflare Pages）

```bash
npx wrangler@latest pages deploy . --project-name online-ps --branch master
```

## 实现说明补充
- 选区 / 蒙版均以独立的离屏 canvas（白色=选中 / 蒙版显示）表示；绘制管线统一为 `beginPaint → strokeOnTmp → commitPaint`，并用 `destination-in` 把绘制结果裁剪到选区或蒙版，避免破坏选区外像素
- 曲线调色用 256 项 LUT（线性插值），RGB/R/G/B 四通道独立映射，作用于当前图层（含选区裁剪）
