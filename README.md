# 在线 PS · 图片编辑器

一个**零依赖、单文件**的在线图片编辑器，类似在线版的 Photoshop。双击 `index.html` 即可使用，也可部署到任意静态托管（已上线 Cloudflare Pages）。

- 线上地址：https://online-ps.pages.dev/
- 代码仓库：https://gitee.com/li-luoqiang/online-ps

## 特性

### 图层系统
- 多图层：新建 / 复制 / 删除 / 向下合并
- 图层显隐、透明度调节、缩略图预览、双击重命名

### 绘制与文字
- 画笔、橡皮擦（可调大小与不透明度）
- 形状：矩形、椭圆、直线、箭头
- 文字工具（浮动输入框，回车提交）
- 渐变工具：线性 / 径向双色填充
- 裁剪、取色

### 调整与滤镜
- 基础调整：亮度、对比度、饱和度、色相、模糊（实时预览 + 应用）
- 一键滤镜预设：复古、鲜艳、冷调、暖调、黑白、反相、素描、柔光
- 锐化（卷积）

### 变换
- 自由变换：选中图层显示变换框，拖控制点缩放、顶部圆点旋转，`Enter` 应用 / `Esc` 取消
- 图层 / 画布 水平、垂直翻转
- 画布旋转 90°、改尺寸

### 颜色
- 前景色 / 背景色双色板，一键交换（X）

### 导出与工程
- 导出 PNG / JPG / WebP
- 保存工程（`.json`，含全部图层）、打开工程继续编辑
- 打开本地图片作为底图

### 历史
- 基于快照的撤销 / 重做（上限 30 步）
- 可点击的历史面板：点任意步骤跳转到该状态

## 快捷键

| 键 | 功能 |
| --- | --- |
| `V` | 移动 |
| `B` | 画笔 |
| `E` | 橡皮擦 |
| `R` / `O` / `L` / `A` | 矩形 / 椭圆 / 直线 / 箭头 |
| `G` | 渐变 |
| `T` | 文字 |
| `C` | 裁剪 |
| `Ctrl+T` | 自由变换 |
| `I` | 取色 |
| `X` | 交换前景/背景色 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Enter` | 应用裁剪 / 自由变换 |
| `Esc` | 取消裁剪 / 自由变换 |
| `Delete` | 取消裁剪框 |

## 技术说明

- 纯原生 HTML5 Canvas + JavaScript，**零第三方依赖、零构建**
- 图层 = 各自的离屏 `<canvas>`，合成时按透明度叠绘到主画布
- 历史快照 = 克隆各图层 canvas（同步、无异步解码坑）
- 自由变换通过 `translate + rotate + drawImage` 实现
- 移动端未专门适配，建议使用桌面浏览器

## 本地运行

直接双击 `index.html`，或起一个静态服务器：

```bash
npx serve .        # 或 python -m http.server
```

## 部署（Cloudflare Pages）

```bash
npx wrangler@latest pages deploy . --project-name online-ps --branch master
```
